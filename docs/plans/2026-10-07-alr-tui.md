# alr TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Textual full-screen view to `alr`: one main window with three panes, setup dialogs over it, an explicit Start, a commit setting (per task or after all tasks), a logging toggle, Stop, and `--install-skill`.

**Architecture:** The engine gains a second commit mode. A new `alr.tui` package hosts the engine as an async Textual worker in the app's own event loop; the stream front end's `report` callback becomes Textual messages that three panes consume. Setup runs in modal dialogs that reuse the run's own checks. `alr.cli` opens the view when stdin and stdout are terminals.

**Tech Stack:** Python 3.12+, `asyncio`, Textual, PyYAML, pytest, pytest-asyncio, pexpect (e2e only), ruff, uv.

**Spec:** `docs/design/00_overview.md` (v6), `01_requirements.md` (v4), `02_architectural_decisions.md` (v6, ADR-012 to ADR-016), `03_system_architecture.md` (v5). Read ADR-012 to ADR-016 before starting.

## Global Constraints

- Python 3.12 or later; `src/` layout; uv for everything (`uv run ...`).
- Runtime dependencies: PyYAML and Textual. Dev dependencies: `pytest`, `pytest-asyncio`, `ruff`. The e2e `requirements.txt` gains `pexpect`.
- Import rules: `alr.engine` imports none of `alr.plain`, `alr.stream`, `alr.tui`. `alr.plain` and `alr.stream` never import each other. `alr.tui` imports `alr.stream`, `alr.engine`, `alr.tasks`, `alr.errors` and never `alr.plain` or `alr.cli`. `alr.engine` never writes to stdout or stderr.
- `--commit` keeps its meaning. `--commit-after-all` is new; passing both is a `UsageError`.
- The view always commits; its commit setting is per task (default) or after all tasks.
- A folder `sandbox.json` is the default permission choice; with none, nothing is pre-selected and Start stays disabled. An explicit skip always wins.
- Nothing is written to `tasks.yaml` before Start passes every startup check.
- The only run control is Stop (button and Ctrl-C). No pause, skip, or retry.
- No second run in one session; no editing of `tasks.yaml` or `sandbox.json` in the viewer.
- Type-hint every function signature. Catch specific exceptions. Re-raise with `raise ... from ...`.
- Code shape: return early, no deep nesting, a blank line after every `if` block, one job per function, a callback longer than a line or two is a named function, comments say why.
- No inline lint or security suppressions (`# noqa`, `# nosec`). Keep every existing docstring.
- Unit tests keep one case per branch (ADR-011). The e2e suite is black-box and shares nothing with the unit suite (ADR-010).
- Gate for every task: `make test` passes (ruff format, ruff lint, unit tests). `make build` runs the e2e suite in a container.
- Commit message trailer: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Commit with explicit pathspecs. Never push.
- Textual API details below were written from its docs; confirm any signature you are unsure of with Context7 (`/websites/textual_textualize_io`) before relying on it. The tests are the contract.

## Review Focus

Failure modes the spec implies but no single task's happy-path tests would catch, most likely first:

1. **`shared.gates: []` versus an absent key.** An empty list means "decided: none" and must not open the Gates dialog; only an absent key does. (Task 10)
2. **An invalid `sandbox.json`** (not JSON, or not an object) found in the folder or picked in the dialog must show an error in the dialog and never fall back to unsandboxed. (Task 9)
3. **Stop between tasks and while idle.** Stop while no session is running still ends the run as stopped, and Ctrl-C when nothing is running quits the app. (Task 6)
4. **Start pressed twice or while running** starts exactly one run. (Task 6)
5. **A failed startup check on Start** (dirty tree, task file not ignored, log folder not ignored) shows an error pop-up, leaves the app Ready, and leaves `tasks.yaml` byte-for-byte unchanged, including unsaved gate edits. (Tasks 6, 10, 12)
6. **A run where every task is already completed** finishes at once as done, and an after-all run makes no empty commit. (Tasks 1, 6)

```python
    """Commit what the task left in the work tree, named after the task; return its final outcome."""
    error = await _commit_changes(repo, task, front_end, [task.name])
    if error is None:
        return COMPLETED, ""

    repo: Repo, tasks: Sequence[Task], front_end: FrontEnd
) -> str | None:
    """Commit everything the run left in the work tree, once; return why git refused, or None.
```

```python
async def _run_loop(
    task_list: TaskList, options: RunOptions, front_end: FrontEnd
) -> None:
    ran: list[Task] = []
    for task in task_list.tasks:
        if task.state == COMPLETED:
            front_end.task_skipped(task)
            continue

        await _run_and_save(task, task_list, options, front_end)
        ran.append(replace(task))

    await _commit_after_all(ran, options, front_end)


async def _commit_after_all(
    ran: Sequence[Task], options: RunOptions, front_end: FrontEnd
) -> None:
    """Commit the whole run once; a failed run never gets here, so its work stays in the tree."""
    if options.repo is None or options.commit_mode is not CommitMode.AFTER_ALL:
        return

    if not ran:
        return

    try:
        error = await commit_all(options.repo, ran, front_end)
    except asyncio.CancelledError:
        raise RunCancelledError("stopped during the final commit") from None

    if error is not None:
        raise RunError(f"commit failed: {error}")
```

```python
"""What a full-screen run is set up with, and whether it can start yet."""

from dataclasses import dataclass
from enum import StrEnum
from pathlib import Path

from alr.engine.commit import CommitMode
from alr.engine.sandbox import bypass_args, sandbox_args
from alr.tasks import Gate


class Permissions(StrEnum):
    """How sessions run; UNSET until the user chooses, so nobody runs unsandboxed by accident."""

    UNSET = "unset"
    SANDBOX = "sandbox"
    SKIP = "skip"


@dataclass
class RunSettings:
    """The values the flags and the dialogs fill, and the run is started from."""

    tasks_file: str = ""
    sandbox_file: str = ""
    permissions: Permissions = Permissions.UNSET
    commit_mode: CommitMode = CommitMode.PER_TASK
    logging: bool = True
    log_dir: str = ""
    """An explicit --log-dir; empty means a logs folder beside the task file."""

    gate_timeout: str = ""
    gates: list[Gate] | None = None
    """Gates edited in the view; None when they were not touched."""

    def missing(self) -> str | None:
        """Say what stops a run from starting, or None when nothing does."""
        if not self.tasks_file:
            return "choose a run folder"

        if self.permissions is Permissions.UNSET:
            return "choose how sessions run"

        if self.permissions is Permissions.SANDBOX and not self.sandbox_file:
            return "choose a sandbox settings file"

        return None

    def session_args(self) -> list[str]:
        """Return the Claude flags for the chosen permissions; the settings file is read here."""
        if self.permissions is Permissions.SKIP:
            return bypass_args()

        return sandbox_args(self.sandbox_file)

    def log_folder(self) -> Path:
        """Where the run's log folder goes."""
        if self.log_dir:
            return Path(self.log_dir)

        return Path(self.tasks_file).parent / "logs"
```

```python
"""The bridge from the engine's events to Textual messages."""

from collections.abc import Callable

from textual.message import Message

from alr.stream.events import Event


class RunEvent(Message):
    """One engine event, delivered to the app."""

    def __init__(self, event: Event) -> None:
        super().__init__()
        self.event = event


def make_report(
    post: Callable[[Message], bool],
    record: Callable[[Event], None] | None = None,
) -> Callable[[Event], None]:
    """Build the stream front end's report callback.

    It holds only the function that posts messages, never the app or a widget,
    so the front end cannot pin them. The run log's writer, when there is one,
    sees each event first: a record that failed to write must stop the run
    before the screen shows an event the record lacks.
    """

    def report(event: Event) -> None:
        if record is not None:
            record(event)

        post(RunEvent(event))

    return report
```

```python
        self.add_column("ID", key="id")
        self.add_column("Task", key="name")

        """Fill the table from the file's tasks, as they stand now."""
        self.clear()
        for task in task_list.tasks:
            symbol = _SYMBOLS.get(task.state, _PENDING)
            self.add_row(symbol, str(task.id), task.name, key=str(task.id))

        if isinstance(event, TaskStarted):
            self._set_state(event.task.id, _RUNNING)

    def on_data_table_row_highlighted(self, message: DataTable.RowHighlighted) -> None:
        if message.row_key.value is not None:
            self.post_message(self.Selected(int(message.row_key.value)))

    def _set_state(self, task_id: int, symbol: str) -> None:
        self.update_cell(str(task_id), "state", symbol)

    """The selected task's activity lines."""

        super().__init__()
        self._lines: dict[int, list[str]] = {}
        self._shown: int | None = None

    def show(self, task_id: int) -> None:
        """Switch to a task and redraw what it has said so far."""
        self._shown = task_id
        self.clear()
        self.write_lines(self._lines.get(task_id, []))

    def apply(self, event: Event) -> None:
        if not isinstance(event, Activity):
            return

        self._lines.setdefault(event.task.id, []).append(event.line)
        if event.task.id == self._shown:
```

```python
"""What Start does before a run: the startup checks again, then the saves."""

from collections.abc import Callable
from dataclasses import dataclass
from datetime import datetime
from importlib import metadata
from pathlib import Path

from alr.engine.commit import Repo, check_log_dir, open_repo
from alr.engine.loop import RunOptions, load_tasks
from alr.errors import RepoError
from alr.stream.events import Event
from alr.stream.runlog import Info, RunLog, run_dir
from alr.tasks import TaskList, save_tasks
from alr.tui.settings import Permissions, RunSettings


@dataclass
class Prepared:
    """A run that passed every check and is ready to hand to the engine."""

    task_list: TaskList
    options: RunOptions
    log: RunLog | None = None

    @property
    def record(self) -> Callable[[Event], None] | None:
        return None if self.log is None else self.log.record

    def close(self) -> None:
        if self.log is not None:
            self.log.close()


async def prepare(settings: RunSettings) -> Prepared:
    """Check everything a run starts with; nothing is written before every check passes.

    The dialogs checked their own answers as they were given, but the files
    and the repository can change meanwhile, so the checks run again here on
    the values the run will use.
    """
    task_list = load_tasks(settings.tasks_file)
    repo = await open_repo(settings.tasks_file)
    if repo is None:
        raise RepoError(
            "not a git repository: start alr inside the project's work tree"
        )

    session_args = settings.session_args()
    log_path = await _check_log_folder(settings, repo)
    _save_gates(settings, task_list)
    options = RunOptions(
        tasks_file=settings.tasks_file,
        gate_timeout=settings.gate_timeout,
        session_args=session_args,
        repo=repo,
        commit_mode=settings.commit_mode,
    )
    log = None if log_path is None else _open_log(settings, log_path)
    return Prepared(task_list, options, log)


async def _check_log_folder(settings: RunSettings, repo: Repo) -> Path | None:
    """Return the new run's log folder, or None with logging off; refuse one git can see."""
    if not settings.logging:
        return None

    path = run_dir(settings.log_folder(), datetime.now().astimezone())
    try:
        await check_log_dir(repo, str(path))
    except RepoError as exc:
        raise RepoError(
            f"the log folder {settings.log_folder()} is not ignored by git; "
            "add it to .gitignore or turn logging off"
        ) from exc

    return path


def _save_gates(settings: RunSettings, task_list: TaskList) -> None:
    if settings.gates is None:
        return

    task_list.shared.gates = settings.gates
    save_tasks(settings.tasks_file, task_list)


def _open_log(settings: RunSettings, path: Path) -> RunLog:
    skip = settings.permissions is Permissions.SKIP
    info = Info(
        version=metadata.version("alr"),
        tasks_file=settings.tasks_file,
        permissions="skip" if skip else "sandbox",
        sandbox_settings="" if skip else settings.sandbox_file,
        gate_timeout=settings.gate_timeout,
        # The view always commits.
        commit=True,
    )
    return RunLog.open(path, info)
```

```python
        # Textual receives Ctrl-C as a key press, so it must be taken here or it quits.
        Binding("ctrl+c", "stop", "Stop", priority=True),
        Binding("q", "quit_if_idle", "Quit"),
    ]

    def __init__(self, settings: RunSettings) -> None:
        super().__init__()
        self.settings = settings
        self.state = AppState.SETUP
        self.outcome = ""
        self._stopping = False
        self._worker: Worker[None] | None = None
        self._task_list: TaskList | None = None

    def compose(self) -> ComposeResult:
        yield Header()
        with Horizontal(id="strip"):
            yield Select(
                [("per task", CommitMode.PER_TASK), ("after all", CommitMode.AFTER_ALL)],
                value=self.settings.commit_mode,
                allow_blank=False,
                id="commit",
            )
            yield Switch(value=self.settings.logging, id="logging")
            yield Button("Start", id="start", variant="success")
            yield Static("", id="reason")
        with Horizontal(id="panes"):
            yield TasksPane(id="tasks")
            yield ActivityPane(id="activity")
            yield GatesPane(id="gates")
        yield Static("", id="status")
        yield Footer()

    def on_mount(self) -> None:
        # After the first refresh, so the table has its columns before it gets rows.
        self.call_after_refresh(self._load_tasks)
        self._refresh()
        loop = asyncio.get_running_loop()
        loop.add_signal_handler(signal.SIGTERM, self.action_stop)

    def _load_tasks(self) -> None:
        """Show the tasks before Start; an unreadable file is reported by the dialogs."""
        if not self.settings.tasks_file:
            return

        try:
            self._task_list = load_tasks(self.settings.tasks_file)
        except AlrError:
            return

        self.query_one(TasksPane).load(self._task_list)

    def on_unmount(self) -> None:
        asyncio.get_running_loop().remove_signal_handler(signal.SIGTERM)

    def _refresh(self) -> None:
        """Bring the Start button and the reason line in line with the state."""
        if self.state in (AppState.RUNNING, AppState.FINISHED):
            self.query_one("#start", Button).disabled = True
            return

        reason = self.settings.missing()
        self.state = AppState.SETUP if reason else AppState.READY
        self.query_one("#start", Button).disabled = reason is not None
        self.query_one("#reason", Static).update(reason or "")

    def on_button_pressed(self, message: Button.Pressed) -> None:
        if message.button.id == "start":
            self.action_start()

    def on_select_changed(self, message: Select.Changed) -> None:
        if message.select.id == "commit" and isinstance(message.value, CommitMode):
            self.settings.commit_mode = message.value

    def on_switch_changed(self, message: Switch.Changed) -> None:
        if message.switch.id == "logging":
            self.settings.logging = message.value

    def action_start(self) -> None:
        if self.state is not AppState.READY:
            return

        # RUNNING at once, so a second press before prepare returns starts nothing.
        self.state = AppState.RUNNING
        self._refresh()
        self._worker = self.run_worker(self._run(), name="run", exit_on_error=False)

    def action_stop(self) -> None:
        if self.state is not AppState.RUNNING:
            self.exit()
            return

        self._stopping = True
        if self._worker is not None:
            self._worker.cancel()

    def action_quit_if_idle(self) -> None:
        if self.state is not AppState.RUNNING:
            self.exit()

    async def _run(self) -> None:
        try:
            prepared = await prepare(self.settings)
        except AlrError as exc:
            # READY lets the refresh recompute the state from the settings.
            self.state = AppState.READY
            self._refresh()
            self.push_screen(ErrorDialog(str(exc)))
            return

        self.query_one(TasksPane).load(prepared.task_list)
        front_end = StreamFrontEnd(make_report(self.post_message, prepared.record))
        try:
            await run(prepared.task_list, prepared.options, front_end)
        except AlrError:
            # The engine already reported RunDone with the reason.
            pass
        finally:
            prepared.close()

    def on_run_event(self, message: RunEvent) -> None:
        event = message.event
        self.query_one(TasksPane).apply(event)
        self.query_one(ActivityPane).apply(event)
        self.query_one(GatesPane).apply(event)
        if isinstance(event, RunDone):
            self._finish(event)

    def on_tasks_pane_selected(self, message: TasksPane.Selected) -> None:
        self.query_one(ActivityPane).show(message.task_id)

    def _finish(self, event: RunDone) -> None:
        self.state = AppState.FINISHED
        self.outcome = _outcome(event, self._stopping)
        self.query_one("#status", Static).update(f"{self.outcome} in {event.seconds:.1f}s")
        self._refresh()
        self.push_screen(SummaryDialog(self.outcome, event.seconds, event.error))


def _outcome(event: RunDone, stopping: bool) -> str:
    """Name how the run ended.

    Only the user's own Stop is a stop: the text of a cancelled run varies
    ("stopped", or "task 1: name: stopped"), and a run that finished clean
    stays done even if Stop raced it.
    """
    if event.error is None:
        return "done"

    return "stopped" if stopping else "failed"


def run_app(settings: RunSettings) -> int:
    """Run the view to the end; 0 only when the run finished clean."""
    app = AlrApp(settings)
    app.run()
    return 0 if app.outcome == "done" else 1
```

```python
from dataclasses import dataclass
from pathlib import Path

from alr.engine.commit import work_tree_root
from alr.engine.loop import load_tasks
from alr.engine.sandbox import folder_sandbox
from alr.errors import RepoError, UsageError
from alr.tasks import TaskList


@dataclass(frozen=True)
class FolderCheck:
    """A run folder that passed: its task file, the loaded tasks, and its sandbox.json if any."""

    tasks_file: str
    task_list: TaskList
    sandbox_file: str


async def check_folder(folder: str) -> FolderCheck:
    """Accept a run folder, or raise why not.

    The view always commits, and commits go into the work tree around the
    working directory (as in the engine), so that is what must exist.
    """
    tasks_file = Path(folder) / "tasks.yaml"
    if not tasks_file.is_file():
        raise UsageError(f"no tasks.yaml in {folder}")

    task_list = load_tasks(str(tasks_file))
    if await work_tree_root() is None:
        raise RepoError("not a git repository: start alr inside the project's work tree")

    return FolderCheck(str(tasks_file), task_list, folder_sandbox(folder) or "")
```

```python
class GatesDialog(ModalScreen[list[Gate] | None]):
    """Add and remove the file's shared gates; Done with none is a decision that there are none."""

    def __init__(self, gates: list[Gate]) -> None:
        super().__init__()
        self._gates = list(gates)

    def compose(self) -> ComposeResult:
        with Vertical(id="dialog"):
            yield Label("Gates, run after each task's session")
            yield ListView(*(self._item(gate) for gate in self._gates), id="list")
            yield Input(placeholder="command", id="cmd")
            yield Input(placeholder="timeout, such as 5m (optional)", id="timeout")
            yield Static("", id="error")
            with Horizontal():
                yield Button("Add", id="add")
                yield Button("Remove", id="remove")
                yield Button("Done", id="done", variant="primary")
                yield Button("Cancel", id="cancel")

    async def on_button_pressed(self, message: Button.Pressed) -> None:
        match message.button.id:
            case "add":
                await self._add()
            case "remove":
                await self._remove()
            case "done":
                self.dismiss(self._gates)
            case "cancel":
                self.dismiss(None)

    async def _add(self) -> None:
        cmd = self.query_one("#cmd", Input).value.strip()
        timeout = self.query_one("#timeout", Input).value.strip()
        error = _gate_error(cmd, timeout)
        self.query_one("#error", Static).update(error or "")
        if error:
            return

        gate = Gate(cmd=cmd, timeout=timeout)
        self._gates.append(gate)
        await self.query_one("#list", ListView).append(self._item(gate))

    async def _remove(self) -> None:
        index = self.query_one("#list", ListView).index
        if index is None:
            return

        del self._gates[index]
        await self.query_one("#list", ListView).pop(index)

    @staticmethod
    def _item(gate: Gate) -> ListItem:
        suffix = f"  ({gate.timeout})" if gate.timeout else ""
        return ListItem(Label(gate.cmd + suffix))


def _gate_error(cmd: str, timeout: str) -> str | None:
    if not cmd:
        return "a gate needs a command"

    if not timeout:
        return None

    try:
        parse_timeout(timeout)
    except ValueError as exc:
        return f"timeout: {exc}"

    return None
```

```python
"""--install-skill: copy the bundled gralph-docs-writer skill into the user's skills folder."""

import shutil
from importlib.resources import as_file, files
from pathlib import Path

from alr.errors import SkillInstallError

_NAME = "gralph-docs-writer"


def install(home: Path | None = None) -> Path:
    """Replace the installed skill with the bundled one and return where it went.

    Nothing compares the two later (gralph ADR-022), so a missing or edited
    skill never stops a run.
    """
    target = (home or Path.home()) / ".claude" / "skills" / _NAME
    try:
        with as_file(files("alr") / "skills" / _NAME) as source:
            if target.exists():
                shutil.rmtree(target)

            shutil.copytree(source, target)
    except OSError as exc:
        raise SkillInstallError(f"--install-skill: {target}: {exc.strerror}") from exc

    return target
```

```python
"""The full-screen view, driven through a pseudo-terminal like a user would."""

import os
from pathlib import Path

import pexpect
from e2e_helpers import (
    find_alr,
    read_tasks_yaml,
    shared_block,
    task_states,
    wait_for_file,
    write_tasks_yaml,
)

TASKS = (
    shared_block(gates=[])
    + """tasks:
  - id: 1
    name: First task
    prompt: Do it.
"""
)

CTRL_C = "\x03"


def _spawn(folder: Path, extra_env: dict[str, str]) -> pexpect.spawn:
    """Start alr on the folder; TERM lets Textual draw, --skip-permissions answers that step."""
    env = {**os.environ, "TERM": "xterm-256color", **extra_env}
    return pexpect.spawn(
        find_alr(),
        ["-d", str(folder), "--skip-permissions"],
        env=env,
        encoding="utf-8",
        timeout=30,
        dimensions=(40, 140),
    )


def test_view_runs_a_task_to_done(git_repo: Path, fake_claude: Path) -> None:
    folder = git_repo / "run"
    tasks_path = write_tasks_yaml(folder, TASKS)
    child = _spawn(folder, {})
    try:
        child.send("s")
        child.expect("Run done")
        # Ctrl-C quits when nothing is running; the summary is a modal, which hides plain keys.
        child.send(CTRL_C)
        child.expect(pexpect.EOF)
    finally:
        child.close(force=True)

    assert child.exitstatus == 0
    assert task_states(read_tasks_yaml(tasks_path)) == {1: "completed"}


def test_view_stop_ends_a_blocked_run_as_stopped(
    git_repo: Path, fake_claude: Path, tmp_path: Path
) -> None:
    folder = git_repo / "run"
    tasks_path = write_tasks_yaml(folder, TASKS)
    ready_file = tmp_path / "ready"
    child = _spawn(folder, {"FAKECLAUDE_BLOCK": "1", "FAKECLAUDE_READY_FILE": str(ready_file)})
    try:
        child.send("s")
        wait_for_file(ready_file, 20)
        child.send(CTRL_C)
        child.expect("Run stopped")
        child.send(CTRL_C)
        child.expect(pexpect.EOF)
    finally:
        child.close(force=True)

    assert child.exitstatus == 1
    assert task_states(read_tasks_yaml(tasks_path)) == {1: "pending"}
```

- **Spec coverage:** the engine commit mode (ADR-014) is Tasks 1 and 2. The in-process worker, the adapter, the panes, and Stop (ADR-012) are Tasks 4 and 6. The four states, Start, the settings strip, the summary, and terminal detection (ADR-013) are Tasks 6, 7, and 11. - **Where the plan departs from the spec's wording:**
  1. A run's outcome is decided by `RunDone.error` plus the app's own stop flag, not by the text `stopped`: a cancelled run's error is `task N: name: stopped` when a task was in flight, and only a bare `stopped` between tasks (`_error_text` returns `str(exc)` for any `RunError`). ADR-012 and `03_system_architecture.md` say the text `stopped` means a cancel; Task 15 can reword that.
  2. The folder dialog's "not a git repository" check looks at the work tree around the working directory, as the engine does (`open_repo` uses `git rev-parse` in the current directory), not at the picked folder itself.
  3. Textual has no menu-bar widget, so the menu is a row of buttons (Task 11).
  4. The strip's permissions control is a button that opens the permissions dialog, since choosing sandbox needs a file path (Task 9); the commit choice is a dropdown.
  5. An after-all commit rides on the last task for the front end's calls, so its hash shows under that task in the gates pane (Task 1).
