# Agentic Loop Runner (alr)

> Maturity: Emerging.  In active, initial development. 
> Version: v0.0.1

`alr` is a command line tool used to run ["ralph loops"](https://ghuntley.com/loop/). The
secondary purpose is to learn Python.
